Grim Dawn Build Check

Reads your character saves on your PC and shows what holds the build back, in the order to fix it.

Download for Windows Windows 10/11, 64-bit. Free and open source. Beta.

What the report shows

Where you stand
Your stage (early, mid, endgame), a score from 0 to 100, the endgame gates that are still open and the next steps, fastest first.
Areas
Health, survival, resistances, bosses, damage, skills, devotions and more, each number next to its target.
Improvements
Concrete fixes by area, each with what it gains and what it costs, and where to get it.
How this is rated
The targets, terms and data behind every number, one click away from each “Why”.

Install

  1. Download and run the installer.

    Windows may warn because the installer is not signed yet: More info → Run anyway.

  2. Start “Grim Dawn Build Check” from the Start menu.

    The first start builds the game data from your own Grim Dawn installation. This takes a few minutes.

  3. Pick a character. The report opens in your browser.

Privacy

  • Your saves are read on your PC. Nothing is uploaded.
  • The source code is open, so you can check that.
  • Every release lists the SHA256 checksum of the installer.
